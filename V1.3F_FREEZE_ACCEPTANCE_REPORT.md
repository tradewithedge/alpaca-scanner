## 3. UI scope validation

The UI now presents two explicitly separated scopes:

**CURRENT SCAN — selected universe**
- SIGNAL ROWS
- QUALITY-ELIGIBLE
- EXECUTION READY
- OUTCOME RECORDED

**SESSION CAPTURE LOG — cumulative across captured universes**
- CAPTURED ROWS
- QUALITY-ELIGIBLE
- EXECUTION READY
- OUTCOME RECORDED

This prevents cumulative session totals from being interpreted as counts for the currently selected universe.
