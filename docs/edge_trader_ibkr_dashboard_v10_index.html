4 · 哪部分判断其实没错

Candidate 没有明显问题；Entry 也不是核心错误。更值得保留的是 Exit Discipline：财报后你没有因为“公司基本面不错”而取消止损，没有把失败 trade 变成长期 investment。

5 · 哪个环节真正失败

  • Event Gate Failure：已知财报只剩约 3 个交易日，普通 swing 仍然获准开仓。
  • Risk Architecture Failure：约 47.7% NAV exposure 对小账户过重，event gap 一出现，损失远超 1R。
  • Stop-model Failure：一旦持有穿越财报，真实下行不再是 Entry − Chart Stop，而是 Entry − Unknown Next Open。

6 · Hindsight Bias 排除

亏损后不能倒推“CSCO 本来就不该买”。真正能在事前被识别并自动阻断的，是 财报日已知 这一事实，而不是事后看到 gap 才说 chart 不好。

7 · Genuine Lesson

好股票 + 尚可技术结构，不能覆盖 binary event risk。

这笔交易真正教会我们的不是“以后别买 CSCO”，而是：任何普通 swing 都不允许在没有明确 event classification 的情况下穿越财报。

8 · Never Repeat Rule

Confirmed earnings ≤ 5 个交易日：普通 Swing Entry = BLOCK。已有仓位财报前必须重新问：“如果现在没有仓位，我会不会以当前价格新买并持有过财报？”若 NO → Reduce / Exit / Reclassify。

6 · Hindsight Bias 排除

后续涨到 $42+，不能反推“stop 不该执行”。如果只是把 stop 放更远但仍买 7 股，风险会更大。正确 lesson 不是取消 stop，而是：Stop 由 thesis invalidation 决定，风险金额由 position size 决定。

7 · Genuine Lesson

方向对、股票对、趋势对，仍然可以亏钱——因为 Trade Architecture 可以错。

GLXY 的核心学费：不要为了“买得起更多股”而把 stop 塞进噪音区。正确顺序永远是 Structure → Stop → Risk Budget → Position Size → Entry。

8 · Never Repeat Rule

A+ Candidate ≠ A+ Entry。若价格明显脱离 EMA8 / EMA20，且没有 new base、pullback、EMA catch-up 或 volatility contraction → WAIT / BLOCK。

任何交易必须先算：合理 stop、每股风险、账户允许亏损、正确股数。若 size 太小或成本失衡 → NO TRADE。

6 · Position Sizing Reconstruction · 当时应该买多少？

以下不是声称 $178 是唯一正确 stop，而是用一个更接近结构性失效区域、约 2 ATR 的 🟡 ASSUMPTION illustrative stop = $178 来重建风险数学。

Position Size 核心公式

Max Shares = (NAV × Risk %) ÷ (Entry − Stop)

FUTU 当时：NAV = $254.36，Entry = $198，Illustrative Stop = $178
所以每股风险 = $198 − $178 = $20 / share。

1% Risk 示例：
允许亏损 = $254.36 × 1% = $2.54
